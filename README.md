# Paradise Taste

A restaurant website for **Paradise Taste**, a home-style Sierra Leonean restaurant in Freetown. Built for the DCOMP 204 Web Design assignment at Limkokwing University of Creative Technology, Sierra Leone.

## About the project

Paradise Taste opened in 2024 to give people in Freetown a clean, reliable place to enjoy home-style cooking at fair prices. This website presents the restaurant, its services, its menu and how to contact it.

The About page includes:

- An introduction to the restaurant with a large photo of the dining room
- An "At a glance" section with key facts: year opened, seats, members and menu items
- A "What we stand for" section: Freshness, Fair price, Hygiene and Local sourcing
- A shared header with navigation and a footer with the address and phone number

## Built with

- HTML5
- CSS3 (Flexbox and Grid, responsive layout)
- Lato font from Google Fonts

## How to run

1. Download or clone this repository:
   ````bash
   git clone https://github.com/bundukajoshua9-source/PARADISE-TASTE.git
   ````
2. Open the project folder.
3. Double-click `about.html` to open it in your browser.

An internet connection is needed to load the Google Fonts.
